# GtkSynapse

Universal AI Desktop Client for Linux

## Features

- Multiple AI provider support (Ollama, Gemini, Groq, OpenRouter, PixVerse)
- Local and cloud-based AI models
- Chat interface with markdown support
- Image and video generation
- Secure API key storage

## Requirements

- Rust 1.80+
- GTK4 development libraries
- libadwaita

## Installation

```bash
git clone https://github.com/MrHoss/GtkSynapse.git
cd GtkSynapse
cargo build --release
./target/release/gtksynapse
```
